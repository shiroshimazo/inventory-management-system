### Left panel (`LoginBrandPanel.tsx`)

Stack order, bottom to top:

1. **Gradient layer** — `absolute inset-0 z-0`, exactly the background the owner supplied:

   ```tsx
   <div
     className='absolute inset-0 z-0'
     style={{
       background: 'radial-gradient(125% 125% at 50% 90%, var(--brand-panel-core) 40%, var(--brand-panel-edge) 100%)'
     }}
   />
   ```

2. **Pattern layer** — `absolute inset-0 z-[1]`, one CSS grid pattern, no asset, no new dependency:

   ```tsx
   <div
     className='absolute inset-0 z-[1]'
     style={{
       backgroundImage:
         'linear-gradient(to right, rgba(255,255,255,0.4) 1px, transparent 1px), linear-gradient(to bottom, rgba(255,255,255,0.4) 1px, transparent 1px)',
       backgroundSize: '56px 56px',
       maskImage: 'radial-gradient(110% 75% at 50% 12%, #000 15%, transparent 72%)',
       WebkitMaskImage: 'radial-gradient(110% 75% at 50% 12%, #000 15%, transparent 72%)',
       opacity: 0.3
     }}
   />
   ```

   The mask keeps the pattern in the violet upper area and fades it out over the white lower area, where white lines would be invisible.

3. **Content layer** — `relative z-10 flex h-full flex-col justify-between`.

   - **Top:** logo badge + product name.
     ```tsx
     <div className='flex items-center gap-3'>
       <div className='flex size-12 items-center justify-center rounded-lg bg-white p-1'>
         <img src={logoImage} alt='Inventory Management System' width={40} height={40} className='size-10 object-contain' />
       </div>
       <span className='text-lg font-semibold tracking-tight text-white'>Inventory Management System</span>
     </div>
     ```
     `logoImage` comes from `import logoImage from '@/assets/img/logo.png'` (869×869, 1:1, transparent PNG). Always set `width`, `height` and `alt`.

   - **Bottom:** one short headline + one short sentence, over the white core of the gradient.
     ```tsx
     <div className='max-w-sm'>
       <h2 className='text-2xl font-semibold tracking-tight text-neutral-900'>Manage stock, purchasing and suppliers</h2>
       <p className='mt-2 text-sm text-neutral-700'>Sign in to track inventory levels, purchase orders and stock movements.</p>
     </div>
     ```

   **Contrast rule for this specific gradient:** the core is white at the bottom centre and violet everywhere else. Top content (logo, product name) sits on violet → use white text. Bottom content (headline, sentence) sits on white → use `text-neutral-900` / `text-neutral-700`. Never place white text over the white core and never place near-black text over the violet edge. Check the rendered result, not just the markup.

   - The product name is `Inventory Management System` (`index.html` title). `themeConfig.templateName` is `Inventory` — do not import the config into the panel, just write the name once.

## 6. Behaviour

- `useForm` with `mode: 'onTouched'`, resolver `zodResolver(loginSchema)`.
- `defaultValues`: `{ username: '', password: '', rememberMe: false }`.
- **Schema** (`LoginSchema.ts`): keep the current username and password rules exactly as they are, and add:
  ```ts
  rememberMe: z.boolean().default(false)
  ```
  Password values are never trimmed and are never sent anywhere. Add one case to `LoginSchema.test.mjs` covering `rememberMe`.
- **Submit:** authentication is not wired up in this project and stays that way. Do not call an API, do not add a mock endpoint, do not store credentials, do not add a route guard.
  - Valid submit → `toast.info('UI preview only. Authentication is not connected.')` (same message as today).
  - Invalid submit → `toast.error('Please fix the highlighted fields.')` **and** move focus to the first invalid field. Focus is not implemented today — add it:
    ```tsx
    const handleInvalid = (formErrors: FieldErrors<LoginFormValues>) => {
      const firstField = Object.keys(formErrors)[0] as keyof LoginFormValues | undefined
      if (firstField) setFocus(firstField)
      toast.error('Please fix the highlighted fields.')
    }
    ```
  - Disable the submit button only while the request is in flight (`isSubmitting`), never because the form is incomplete.
- **Validation rules** (`07-Validation-Rules.md`): validate on blur and on submit; red border **plus** an error icon, never colour alone; short message under the field; keep what the user typed; clear the error as soon as the field is fixed; do not show errors on untouched fields.
- When real authentication is connected later, the failure message must be the generic `Incorrect username or password.` Do not build that now — just leave the code ready for it.
