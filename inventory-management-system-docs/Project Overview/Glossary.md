# Glossary

| Term | Definition |
|---|---|
| Admin | A user role with full access to the system, including user management, products, suppliers, orders, and reports. |
| Staff | A user role for store or warehouse employees, with access to stock updates, sales, and limited reports. |
| SKU | Stock Keeping Unit. A unique identifier for a product. |
| Product | An item tracked in the inventory, with a name, SKU, category, unit price, quantity, and reorder level. |
| Category | A grouping used to organize and filter products. |
| Stock level | The current quantity of a product available in the inventory. |
| Stock-in | A movement that increases stock, usually from a received purchase order. |
| Stock-out | A movement that decreases stock, usually from a sale. |
| Stock movement | A logged change to a product's quantity, recording the type (in/out/adjust), quantity, reference, user, and date. |
| Reorder level | The minimum quantity that triggers a low-stock alert for a product. |
| Low-stock alert | A warning shown when a product's quantity falls below its reorder level. |
| Supplier | A company or person that provides products, with contact details. |
| Purchase Order (PO) | A document requesting products from a supplier, containing multiple items and quantities. |
| PO status | The state of a purchase order: Pending, Ordered, Received, or Cancelled. |
| Sale | A transaction that reduces stock and records the products sold, quantities, and prices. |
| Dashboard | The main overview page showing statistics, charts, and recent activity. |
| Report | A summary of inventory, sales, or stock data, optionally filtered by date range. |
| Role-based access control (RBAC) | Restricting system access based on the user's role. |
| SPA | Single-page application. The app loads once and updates the page dynamically without full reloads. |
| Admin shell | The layout containing the sidebar, header, and footer used by authenticated pages. |
| Blank layout | The minimal layout used by authentication pages, without the sidebar or header. |
